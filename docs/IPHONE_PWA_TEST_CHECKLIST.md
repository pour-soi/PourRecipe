# 真实 iPhone 人工测试清单

Codex 不能代替真实 iPhone 验证。以下项目默认均为未验证；只有用户本人完成后才能勾选。

## 测试信息

- 正式 URL（请填你的正式域名）：https://[你的正式域名]
- 站点访问：按实际访问方式进入网站，再使用 PourRecipe 的登录页
- 登录身份：Supabase 中已经创建的唯一 Auth 用户
- 登录方式：Email Magic Link（不使用数字验证码）
- 建议准备：第二个隔离浏览器、一张普通照片、一张中文截图、一张英文截图、一张中英混合截图

## 安装

- [ ] 用 iPhone Safari 打开 HTTPS 正式 URL
- [ ] 通过站点真实访问链路登录（如有门禁按实际流程）
- [ ] 分享菜单选择“添加到主屏幕”
- [ ] 主屏幕图标清晰且正确
- [ ] 从主屏幕图标以独立窗口启动
- [ ] 独立窗口没有 Safari 地址栏
- [ ] 刘海、灵动岛和底部 Home Indicator 的 safe-area 正确
- [ ] 固定浅色界面正常，系统切换深色模式后应用仍保持浅色且对比度清楚

## 登录与同步

- [ ] 设置页显示“当前已登录”
- [ ] 关闭并重新打开后 session 恢复
- [ ] 上传本机数据不会静默覆盖云端

- [ ] 恢复网络后自动或手动同步成功
- [ ] 双端并发修改出现可见冲突
- [ ] “保留本机版本”结果正确
- [ ] “使用云端版本”结果正确
- [ ] 退出登录后本地数据仍可浏览和编辑
